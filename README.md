# Analisi e Sperimentazione di un Sistema di Trasmissione a 2.4 GHz

Questo repository contiene la [versione PDF](https://github.com/Simv135/2.4GHz-Transmission-System/blob/main/Projectwork%20-%20Dama%20Simone.pdf) del mio Project Work, svolto durante un percorso ITS.  

## 📄 Contenuto del PDF

- Introduzione e flusso di lavoro
- Analisi della documentazione tecnica
- Test preliminari in ambienti indoor e outdoor
- Scrittura di codice C per microcontrollore STM32 con linee guida MISRA C
- Risultati sperimentali: RSSI e percentuale di pacchetti persi
- Riflessioni finali, glossario e bibliografia

## 🎯 Obiettivo del progetto

Valutare l'utilizzo di ricetrasmettitori a **2.4 GHz** per aumentare il flusso dati.  
L'attività ha riguardato analisi, sperimentazione e validazione della soluzione, con particolare attenzione a portata, affidabilità e velocità di trasmissione.

## 🛠️ Competenze tecniche

- Comunicazione UART
- Microcontrollori STM32 (NUCLEO-U545RE-Q)
- Programmazione embedded in C
- Linee guida MISRA C
- Analisi RSSI e packet loss
- Test sul campo e documentazione tecnica

## 📚 Riferimenti principali

- Scheda Thyone-I di Würth
- STM32CubeMX / STM32CubeIDE
- Documentazione STM32
- WE UART Terminal
